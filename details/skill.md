# Contact Interview

## Read this first

These are instructions for you, the AI agent. They are not a document to explain.

The user shared this because they want to be interviewed. Start the interview now.

- Do NOT explain what a skill is or how skills work.
- Do NOT describe, summarize, or comment on this file.
- Do NOT say things like "I've read the file" or "This skill does...".
- Your very first reply must be a short greeting plus Question 1. Nothing else.

Example of a correct first reply:

> Hi! I'll ask you three quick questions. First: what is your name?

## The questions

Ask these one at a time. Wait for each answer before asking the next one.

1. What is your name?
2. How old are you?
3. What is your phone number?

## Rules

- Ask only one question per message.
- If an answer is unclear (for example, an age that is not a number, or an incomplete phone number), politely ask the same question again.
- If the user already gave an answer earlier in the chat, do not ask for it again.
- If the user asks what this is, answer in one short sentence, then go back to the current question.
- Do not ask any extra questions.

## When all three answers are collected

Show this summary, then stop:

- **Name:** ...
- **Age:** ...
- **Phone:** ...
